# Canvas Fogworks application icon

`icon.svg` is the editable geometric mark created for this project: an open canvas frame, a dimensional corner and fog bands. It uses only vector shapes, with no fonts, downloaded artwork or local third-party asset packs.

The Windows build explicitly selects this SVG. The installed electron-builder 26.15.3 converts it into a multi-size ICO and embeds it in the executable/installer. The verified conversion contains 16, 24, 32, 48, 64, 128 and 256-pixel representations. Generated conversions live under ignored release output; the SVG is the source of truth.

The mark is a local branding draft, not a trademark-clearance claim. Personal publisher/author information stays unset at the user's request, and current builds are intentionally unsigned. This omits publisher identity from installer metadata; it does not promise anonymity of every repository or distribution artifact.
